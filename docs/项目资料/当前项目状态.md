## 旧校验管线说明

`词境/scripts/verify-final-example-library.py` 现以 `data/context-resolved-examples.js` 为默认发布源，同时校验前端分片和完整静态库是否完全一致。它允许仅在标记为“已审校且语义不同”时使用合并来源义项，未审校的合并义项仍会被拒绝。

后续维护例句数据时，必须先运行语义去重构建和最终库校验，再确认 `ai-example-index.js`、`released-example-words.js` 与发布源完全一致。旧候选数据和旧审计报告均保留在 `词境/data/`，未作删除或修改。历史项目、交接和发布文档已完整合并为一份总档。

## 已确认的产品与运维原则

- 学习、复习、词本、导入记录和设置以本地数据为基础；启用同步时，云端仅保存浏览器端加密后的同步数据，密钥不上传。
- “记忆”是按单词本隔离的手动记忆表，与 FSRS 学习、复习排程完全独立，且仅收录已经学习过的单词。All 显示已学习单词，Learning 显示其中尚未完成最终节点的单词，Mastered 显示已勾选 Day 30 的单词；每个目录从 1 重新编号。勾选 Day 30 后会保留当前横向滚动位置，并以淡出收起方式自然移入 Mastered；iPad/iPhone 上的 Mastered 最终列保留清晰显示与点击空间。搜索输入英文或中文后可点击“跳转”或按回车，列表会定位并滚动到目标行，不会只筛选单个匹配项。点击序号会在全部已核验例句准备完成后一次性显示双语内容；同义、近义或仅词性变化的中文释义只保留一个例句，优先展示语义真正不同的义项；每句均有统一位置的朗读按钮，目标词形会突出显示；iPhone 上面板标题固定、例句区域独立上下滚动，并始终覆盖底部导航。记忆页另设与目录完全分开的单层空白“学习备忘”便签，内容由用户自行输入并自动保存；启用同步时会随浏览器加密数据同步。
- iPhone/iPad 通过 Safari 或添加到主屏幕使用；Windows 启动与桌面图标相关文件位于 `词境/start.cmd`、`start.ps1`、`launch.vbs` 和 `创建桌面图标.ps1`。
- Cloudflare 正式站点已于 2026-08-30 发布独立记忆页；首页、记忆页脚本、样式与缓存脚本均已在线回读确认。
- 不把旧的 Codex CLI、后台自动化或旧候选例句管线当作应用的必要运行条件。

## 后续验证重点

1. 若要重新发布，先运行 `npm.cmd run content:verify` 与 `npm.cmd run ios:web:prepare`，再核对前端例句分片、发布白名单、Service Worker 缓存版本和 Cloudflare Worker 配置是否来自同一构建。
2. 在 Windows、iPhone 和 iPad 上验证启动、PWA 更新、学习/复习滚动规则和同步状态。
3. 为旧的最终校验脚本建立与现行分片相同的数据入口，再把校验结果写回本文件。
