## 已核实的问题

- 原生成器只做格式检查。合并程序自动写入 `contextReviewed` 与 `semanticDistinct`，这些标记不能作为独立语义复核证据。

- 这 20 词须逐项复核词典和例句后处理。不能直接删掉词典未列出的全部用法：例如 association 的“关联”、bull 的“看涨者”需要核实和保留适当覆盖。cafe 的“酒店”标签与句中咖啡馆含义不符；curriculum 的两条近义用法、laughter 的笑声/大笑例句需合并复核；vocabulary 留有填空模板句。
- 已接受草稿也有语义复核需求：wealth 的财富/富裕、trolley 的手推车/台车不能仅凭不同义项 ID 判断为语义不同。此前单批抽查不足以证明合格。
- 计划按词典顺序选前五个分组，未证明所选均为最常用、最值得覆盖的义项；未进入计划的 562 词和保留例句同样需要内容复核。
